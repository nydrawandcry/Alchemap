# Alchemap

Хотим представить вам приложение, созданное в рамках pet-проекта для личного пользования - настольная алхимическая лаборатория для D&D. 
Алхимап упрощает работу с зельями в алхимии днд, автоматизирует подсчеты и позволяет сохранять понравившиеся рецепты в ваш журнал.

А мастер может задавать собственные результаты и условия их получения!

## Гайд по установке и запуску (для обычных ПК-бояр)

Готовые сборки для Windows публикуются в разделе
[Releases](https://github.com/nydrawandcry/Alchemap/releases).

1. Откройте нужный релиз и скачайте из **Assets** архив
   `Alchemap-<версия>-windows.zip`.
2. Полностью распакуйте архив в удобную папку.
3. Откройте папку `Alchemap` и запустите `Alchemap.exe` двойным щелчком.

Сохраняйте файлы и папки `app` и `runtime` рядом с
`Alchemap.exe`: они нужны для работы приложения. Для удобства можете создать ярлык на рабочий стол.

Архив **Source code (zip)**, который GitHub добавляет автоматически, содержит
исходный код. Для запуска готовой программы скачивайте архив с названием
`Alchemap-<версия>-windows.zip`.

## Возможности

- Создание и полное удаление ингредиентов из каталога.
- Добавление ингредиентов в смесь с выбором количества.
- Измельчение, нарезка, варка, сжигание, охлаждение, фильтрация, перегонка,
  настаивание и сушка ингредиентов.
- Просмотр характеристик смеси, отмена последнего шага и начало нового опыта.
- Сохранение завершённых опытов и рецептов, просмотр рецептов и переименование
  опытов в журнале.
- Редактор мастера: собственные результаты, приоритеты и условия их получения.

После удаления какого-либо ингредиента шаги и результаты ранее
сохранённых рецептов при этом остаются прежними.

## Как пользоваться

1. На вкладке **«Лаборатория»** выберите ингредиент и количество, затем нажмите
   **«Добавить»**. При необходимости создайте собственный ингредиент.
2. Добавьте другие ингредиенты и примените нужные операции.
3. Завершите опыт и задайте ему название. При желании сохраните результат как
   рецепт.
4. Откройте **«Журнал опытов»**, чтобы посмотреть сохранённые записи и рецепты.
5. На вкладке **«Редактор мастера»** настройте результаты и условия для будущих
   опытов.

Незавершённая цепочка действий хранится до закрытия приложения. Для сохранения
опыта завершите его и подтвердите название. Журнал показывает последние 100
опытов, более ранние записи остаются в базе данных, вохможности их посмотреть пока нет.

## Где хранятся данные

По умолчанию используется локальная база H2. При первом запуске приложение
создаёт её и добавляет начальный каталог ингредиентов и правила мастера.

В Windows данные находятся в файле:

```text
%LOCALAPPDATA%\Alchemap\alchemap.mv.db
```

Чтобы открыть эту папку, вставьте `%LOCALAPPDATA%\Alchemap` в адресную строку
проводника. Сохранения относятся к текущей учётной записи Windows и находятся
отдельно от распакованной программы.

Для резервной копии закройте все окна Alchemap и скопируйте файл
`alchemap.mv.db` в другую папку.

## Обновление и удаление

Перед обновлением закройте приложение и сделайте резервную копию базы.
Распакуйте новую версию в отдельную папку и запустите её. Она использует
сохранения той же учётной записи Windows. Проверьте записи перед удалением
старой папки программы.

Чтобы удалить программу, закройте её и удалите распакованную папку `Alchemap`.
Файл базы в профиле юзера при этом сохраняется.

## Если возникла проблема

- Если приложение не запускается, убедитесь, что архив полностью распакован
  и папки `app` и `runtime` находятся рядом с `Alchemap.exe`.
- Если не удаётся открыть хранилище, закройте другие экземпляры Alchemap
  и повторите запуск.
- При сообщении об ошибке приложите её текст, название скачанного архива
  и версию Windows.

## Для разработчиков

Приложение написано на Java 21 с интерфейсом Swing. Сборка выполняется Maven,
доступ к данным через JDBC. По умолчанию используется H2; также поддерживаются
MySQL и демонстрационный режим.

## Требования

- Полный JDK 21 или новее.
- Apache Maven 3.9.x либо встроенный Maven 3 из IntelliJ IDEA.
- Git для получения исходного кода.

Для упаковки Windows-сборки нужен JDK для Windows с утилитой `jpackage`.
Архитектура сборки определяется выбранным JDK. Создание ZIP с режимом `Image`
не требует WiX.

## Получение исходного кода

Основная ветка разработки — `dev`:

```bash
git clone --branch dev --single-branch https://github.com/nydrawandcry/Alchemap.git
cd Alchemap
```

Для воспроизведения конкретного релиза используйте соответствующий тег.

## Сборка и запуск

Из корня проекта выполните:

```bash
mvn clean package
java -jar target/alchemap.jar
```

Команды Maven и Java должны использовать JDK 21 или новее. Проверить окружение
можно через `mvn -version` и `java -version`.

Результат сборки — `target/alchemap.jar`, содержащий приложение и зависимости.
Версия задаётся в `pom.xml`.

### IntelliJ IDEA

1. Откройте проект и подключите `pom.xml` как Maven-проект.
2. Выберите JDK 21 или новее для проекта и Maven Runner.
3. Дождитесь загрузки зависимостей.
4. Дважды нажмите Ctrl и выполните `mvn clean package` через Run Anything.
5. Запустите `AlchemapApplication` либо собранный JAR с тем же JDK.

### Если терминал использует старую Java

Настройки JDK в IDEA и Java в терминале могут различаться. В PowerShell можно
указать JDK явно; замените пример пути своим значением из **JDK home** в IDEA:

```powershell
$alchemapJdk = 'C:\path\to\jdk-21'
& "$alchemapJdk\bin\java.exe" -jar '.\target\alchemap.jar'
```

### Если Maven не может создать локальный репозиторий

В IDEA откройте **Settings → Build, Execution, Deployment → Build Tools →
Maven**, включите **Override** у **Local repository** и задайте доступную
для записи папку. Если путь с кириллицей искажается в сообщении об ошибке,
можно использовать, например, `C:\Users\Public\maven-repository`.

## Хранилища

Приложение читает необязательный `config.properties` из текущей рабочей папки.
Пример находится в `config.example.properties`. Файл с локальными настройками
и паролями исключён из Git через `.gitignore`.

Режим выбирается свойством `storage.type`:

| Значение | Хранилище | Сохранение данных |
| --- | --- | --- |
| `h2` | Локальная файловая H2; используется по умолчанию | Между запусками |
| `mysql` | Внешняя MySQL, подготовленная разработчиком | Между запусками |
| `demo` | Демонстрационное хранилище в памяти | До закрытия приложения |

### H2

Для обычного запуска `config.properties` не нужен. При необходимости явно
выберите локальную базу:

```properties
storage.type=h2
```

Первый запуск автоматически создаёт схему из `resources/db/h2-v1.sql`, начальный
каталог и правила мастера. Повторный запуск сохраняет пользовательские правки
и не восстанавливает удалённые ингредиенты.

В Windows используется `%LOCALAPPDATA%\Alchemap\alchemap.mv.db`. При отсутствии
переменной `LOCALAPPDATA` используется `~/.alchemap/alchemap.mv.db`.

### MySQL

Для режима MySQL скопируйте `config.example.properties` в `config.properties`,
укажите `storage.type=mysql` и свои `db.url`, `db.user`, `db.password`.

В каталоге `database` находятся схема и миграции:

- `database.sql` - начальная схема и данные. Скрипт пересоздаёт таблицы:
  используйте его для новой тестовой базы.
- `migration-v2.sql` - таблицы и начальные правила редактора мастера.
- `migration-v3-hard-delete.sql` - изменение связи для полного удаления
  ингредиентов в существующей базе со старой схемой.

Текущая начальная схема уже содержит `ON DELETE SET NULL`. Подготовка MySQL
выполняется вручную. Данные MySQL и H2 независимы; автоматического переноса
между ними нет.

## Подготовка ZIP для Windows

1. Обновите версию в `pom.xml`, если готовите новый релиз.
2. Проверьте пользовательскую инструкцию `packaging/readme-Windows.txt`.
3. Закройте Alchemap, запущенный из предыдущей папки сборки.
4. Выполните `mvn clean package`.
5. Из корня проекта запустите в PowerShell:

```powershell
$alchemapJdk = 'C:\path\to\jdk-21'
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\packaging\package-windows.ps1 -JdkHome "$alchemapJdk" -Package Image
```

Замените пример пути на свой JDK home. Скрипт создаст приложение со встроенной
Java и архив:

```text
target\windows-package\image\Alchemap\Alchemap.exe
dist\Alchemap-<версия>-windows.zip
```

В архив входят вся папка приложения, Java runtime, JAR и пользовательская
инструкция. Рабочая база и локальный `config.properties` в комплект не входят.
Обычный ZIP-релиз использует локальную H2 по умолчанию.

Каталоги `target` и `dist` исключены из Git. Готовый ZIP прикрепляется как asset
к GitHub Release.

## Проверка и публикация релиза

1. Распакуйте итоговый ZIP в другую папку и запустите `Alchemap.exe` двойным
   щелчком. Проверьте также запуск на Windows без установленных Java и MySQL.
2. Создайте ингредиент, завершите опыт, сохраните рецепт и измените правило
   мастера. Перезапустите приложение и проверьте сохранность данных.
3. Закоммитьте и отправьте исходный код, документацию и скрипты сборки.
4. Создайте GitHub Release с тегом версии, например `v1.0.0`, на соответствующем
   коммите ветки `dev`.
5. Прикрепите `dist/Alchemap-<версия>-windows.zip` и опишите запуск через
   распаковку и `Alchemap.exe`.

Автоматически добавляемый GitHub архив **Source code (zip)** содержит исходный
код и не заменяет собранный ZIP.

## Структура проекта

| Путь | Назначение |
| --- | --- |
| `src/AlchemapApplication.java` | Запуск приложения и открытие хранилища |
| `src/model` | Модели ингредиентов, шагов, результатов и правил |
| `src/engine` | Расчёт свойств смеси и выбор результата |
| `src/controller` | Управление текущим опытом |
| `src/view` | Интерфейс Swing |
| `src/data` | Интерфейс репозитория, JDBC, H2, MySQL и деморежим |
| `resources/db` | Автоматически загружаемая схема H2 |
| `database` | Схема и миграции MySQL |
| `packaging` | Скрипт Windows-сборки и инструкция для архива |
