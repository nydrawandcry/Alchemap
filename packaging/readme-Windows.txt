ALCHEMAP

Алхимическая лаборатория для D&D.

Запуск
Для версии из ZIP распакуйте архив целиком и запустите Alchemap.exe
внутри папки Alchemap. Все файлы и вложенные папки нужны для работы.
Для установленной версии используйте ярлык Alchemap.

Java и MySQL отдельно устанавливать не требуется.

Сохранённые данные
Ингредиенты, опыты, рецепты и правила мастера хранятся в файле:
%LOCALAPPDATA%\Alchemap\alchemap.mv.db

Чтобы открыть папку данных, вставьте в адресную строку Проводника:
%LOCALAPPDATA%\Alchemap

Резервная копия
Закройте все окна Alchemap и скопируйте файл alchemap.mv.db
в выбранную папку резервных копий.
